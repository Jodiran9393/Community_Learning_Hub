React.js

Modern UI library for building interactive interfaces

Getting Started

React is a JavaScript library for building user interfaces. It's maintained by Meta (Facebook) and a community of individual developers and companies.

  • Official React Documentation - The best place to start learning React
  • React Tutorial - Interactive step-by-step tutorial
  • React in 100 Seconds - Quick overview by Fireship

Core Concepts

  • Components - Building blocks of React applications
  • JSX - JavaScript syntax extension for describing UI
  • Props - Passing data between components
  • State - Managing component data that changes over time
  • Hooks - Special functions like useState and useEffect

Learning Path

  • Week 1-2: Learn JavaScript fundamentals and ES6+ features
  • Week 3-4: Understand React basics - components, JSX, props
  • Week 5-6: Master hooks and state management
  • Week 7-8: Build real projects and learn best practices
